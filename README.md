TriggerResponse
===============

A CharaROM fork of [Ripple](https://github.com/guardianproject/ripple) by Guardian Project, via [CalyxOS](https://github.com/CalyxOS/platform_packages_apps_Ripple).

Package name changed from `org.calyxos.ripple` to `com.android.triggerresponse` for better obscurity - blends in with system apps and avoids detection by integrity checkers that flag known privacy tools.

## What is it?

A "panic button" app for triggering a "ripple effect" across apps that are set up to respond to panic events. Works with [EmergencyButton](https://github.com/CharaROMAndroid/android_packages_apps_EmergencyButton) (CharaROM's fork of CalyxOS Panic) to silently uninstall selected apps when triggered.
